Hero source (React + Motion + CSS 3D). You do NOT need this to run the site.
The site only loads assets/hero/hero.js and assets/hero/hero.css (already built).

To change the hero:   npm install && npm run build   (copies to out/assets/hero -> copy hero.js/hero.css into ../assets/hero)
Cards live in src/cards.js. Covers/videos are made by tools/make-covers.mjs.
